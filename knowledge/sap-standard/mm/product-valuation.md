# Product Valuation

## Standard knowledge

SAP S/4HANA documentation describes product valuation at an organizational valuation level and supports valuation types when split valuation is used.

The product valuation model includes the base unit of measure, currency and inventory valuation procedure. SAP documentation identifies standard price and moving average price as price-control options, with additional behavior depending on Material Ledger and price-determination settings.

## Functional boundary

This document establishes SAP Standard concepts only.

It does not establish:

- which valuation level is configured in a customer system;
- which materials use standard or moving average price;
- whether Material Ledger is active for a particular system;
- which valuation categories or valuation types are configured;
- how a customer-specific Z movement determines accounts.
