# SAP S/4HANA MM Standard Knowledge

## Scope

This directory will contain validated knowledge extracted from official SAP documentation for Materials Management.

## Initial topics

The MVP starts with these topic families:

- procurement
- inventory management
- material master
- purchasing
- goods movements
- invoice verification

No topic is considered populated until its source and release context are recorded.

## Classification

All content in this directory is SAP Standard Knowledge unless a future document explicitly states otherwise and provides evidence for a different classification.
