# SAP Help Portal

## Propósito

Fuente oficial de documentación de productos SAP utilizada por agenteSAP para construir la capa de SAP Standard Knowledge.

## URL

https://help.sap.com/docs/

## Uso

La fuente puede aportar:

- documentación funcional;
- documentación de producto;
- información de versiones;
- documentación de APIs;
- información de componentes SAP.

## Regla de uso

El agente debe conservar la referencia a la página oficial concreta utilizada para sustentar una afirmación.

La existencia de una página en SAP Help Portal no convierte automáticamente cualquier interpretación derivada en conocimiento confirmado.

## Evidencia

La documentación oficial debe tratarse como una fuente de alta prioridad para afirmaciones sobre funcionalidad SAP Standard.
